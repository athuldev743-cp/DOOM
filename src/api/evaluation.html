External k6 tests · run from your PC

Public-network percentiles and the real remote MCP handshake must run outside the server. These commands use the same live terminal in your PowerShell window.

Public network loadk6 run -e BASE_URL=https://doom-1a9d9743.fastapicloud.dev -e VUS=5 -e DURATION=1m evaluation/k6/production-load.js
Real MCP protocolSet DOOM_SESSION before running the MCP test.

Start with 5 VUs. The load test targets the lightweight /health endpoint; RAG concurrency is measured separately above. Do not run high-volume stress tests against production.

Measurement boundaries

RAG relevance: curated expected-source scoring, not human-judged relevance. MCP: in-process adapter execution, not an external protocol handshake. LangGraph: invokes the configured LLM and consumes provider tokens. Latency: in-process ASGI measurements, not internet-facing load-test percentiles.

For external throughput and network p95/p99, run k6 from a separate load generator. Test counts are capped to protect the production service.
